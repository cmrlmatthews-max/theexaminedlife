# The Examined Life

The Examined Life is a philosophy learning game. You walk four lands as the Wanderer. You meet thinkers, find their artifacts, play mini-games, and face a boss in each land.

**Play:** https://cmrlmatthews-max.github.io/theexaminedlife/

The game is made for an iPhone in vertical orientation. It also runs in a desktop browser.

## The four lands

- Level I, the Stormcliffs: the meaning-makers (existentialists).
- Level II, the Marble Coast: the ancient schools for a good life.
- Level III, the Misty Valleys: Eastern approaches.
- Level IV, the Clockwork City: the ethics toolkit.

## What is in this repo

- `index.html`: the game.
- `mini/`: the mini-games, boss rounds, music, and voice player.
- `a/`: art, videos, and voice clips. Each file name is the asset id that the code uses.
- `tools/`: the build and art scripts, and the test kit (`examined-life-testkit.py`). These are records of how the game was made. The game does not need them to run.

## Saves

Progress saves in the browser you play in. Cross-device sync works only in the claude.ai copy of the game.

## Main copy

This GitHub repo is the main copy of the game. Each new build phase ends with a push here.
